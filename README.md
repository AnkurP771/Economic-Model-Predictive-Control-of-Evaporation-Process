# Economic-Model-Predictive-Control-of-Evaporation-Process

Implementation of **Model Predictive Control (MPC)** for an industrial evaporator process as part of the **CH516: Advanced Process Control** course.

## 📌 Overview

This project develops and evaluates Model Predictive Control (MPC) strategies to regulate the product concentration of an industrial evaporator while satisfying process constraints. The controller is implemented and tested in **MATLAB** through dynamic simulations under different operating conditions and disturbances.

## 🚀 Features

- Dynamic modeling of an industrial evaporator
- Linear and Nonlinear Model Predictive Control (MPC)
- Setpoint tracking and disturbance rejection
- Constraint handling for process variables
- Performance evaluation through MATLAB simulations

## 🛠️ Technologies Used

- MATLAB
- Model Predictive Control (MPC)
- Process Modeling & Simulation
- Control Systems

## 📈 Results

The implemented MPC controller successfully:
- Maintains desired product concentration
- Rejects process disturbances effectively
- Ensures stable operation under process constraints
- Provides smooth control actions
